# Applied Everything

<ItemImage id="infinity_cell" scale="4" />

Applied Everything adds the <ItemLink id="infinity_cell" />: an ME storage cell that supplies **one item of your choice
without limit**. Any item from any mod can be imprinted, as long as you can pay for the cell.

An imprint cannot be changed later. The cost is the cell itself, and it is the same for every item, so choosing what
to imprint first is part of the game.

## The Road to an Infinity Cell

1. Run a <ItemLink id="ae2:condenser" /> on Singularity mode to turn spare items into
   <ItemLink id="ae2:singularity" /> (256,000 items each).
2. Compress 9 singularities into a <ItemLink id="compressed_singularity" /> with the
   <ItemLink id="singularity_compressor" />. Each compression costs **10,000,000 AE**.
3. Craft an <ItemLink id="infinity_core" /> from 8 compressed singularities and a nether star.
4. Craft a <ItemLink id="blank_infinity_cell" /> from the core, 3 more compressed singularities, 256k storage components
   and an item cell housing.
5. Imprint the blank cell with any item in the <ItemLink id="imprinter" /> to get an <ItemLink id="infinity_cell" />.

One Infinity Cell takes 11 compressed singularities: 99 singularities, or about 25 million condensed items, and
110,000,000 AE of compression.
